# Bookstore-sovellus

Tämä on yksinkertainen Bookstore-sovellus, joka on kehitetty Haaga-Helian ohjelmistokehityksen kurssilla. Sovelluksessa voit tallentaa ja katsella tallennettuja kirjoja, ja siinä on kirjautumisjärjestelmä.

## 🔧 Ominaisuudet
- **Kirjautuminen:** Käyttäjät voivat kirjautua sisään.
- **Kirjat:** Voit lisätä, tallentaa ja tarkastella kirjoja.
- **Tietokanta:** Sovellus käyttää h2-tietokantaa kirjojen tallentamiseen.

## 🛠️ Teknologiat ja kirjastot
- **Backend:** Java (Spring Boot)
- **Tietokanta:** MySQL
- **Rakennustyökalu:** Maven

## 🗂️ Asennus ja käyttö

1. **Lataa ja asenna vaaditut ohjelmistot:**
   - Java 11 tai uudempi
   - Maven
   - h2

2. **Käynnistä sovellus:**
   - Avaa terminaali ja siirry projektikansioon.
   - Suorita komento:
     ```bash
     mvn spring-boot:run
     ```

5. **Kirjautuminen ja kirjojen hallinta:**
   - Sovellukseen pääsee kirjautumaan käyttäjätunnuksella ja salasanalla.
   - Kirjoja voi lisätä ja tarkastella sovelluksessa.
